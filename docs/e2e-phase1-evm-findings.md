## E2E Findings — Bootstrap Phase 1 (EVM)

This log records **discrepancies and observations** for **Bootstrap Phase 1 (EVM)**, always relative to the baseline in `e2e-bootstrap-user-flow-spec.md` and the designed test cases in `e2e-phase1-evm-test-cases.md`.

Use it to track:

- Design vs implementation mismatches.
- Gaps between spec and tests.
- Environment / harness limitations that affect coverage.

### Columns

- **ID**: Stable finding identifier (`F1-<index>` for Phase 1).
- **Category**: `Blocker` / `Non-blocker`.
- **Spec/Test ref**: ID from the user-flow spec section and/or test case ID (e.g. “Stake flow §5 / P1-5.1”).
- **Observation**: What was actually seen.
- **Likely cause**: Implementation bug, spec gap, or environment issue.
- **Status**: `Open` / `Resolved` / `Won’t fix`.
- **Resolution**: How it was (or will be) addressed.
